# NeuroPocket v1.25 Personal — S24 Ultra Acceptance Checklist

**Кандидат:** `NeuroPocket-v1.25-personal-rc.apk` (см. SHA-256 и подпись в финальном отчёте сессии)
**Устройство:** Samsung Galaxy S24 Ultra, 12 ГБ RAM, Android 16, ARM64
**Ветка:** `feature/v1.25-personal-final` (НЕ merged в main — ждёт Lead review + это acceptance)

Как отмечать: `[ ]` → `[x]` (пройдено) / `[!]` (баг — записать в Known issues внизу).

---

## 0. INSTALL / FIRST START

- [ ] APK устанавливается (разрешить установку из неизвестных источников)
- [ ] Первый запуск без краша, онбординг проходится
- [ ] Перезапуск приложения — состояние сохраняется (тема, персона, сессии)

## 1. MODELS

- [ ] Каталог моделей открывается (Модели)
- [ ] Скачивание GGUF-модели работает (Wi-Fi), отмена скачивания + retry
- [ ] Импорт GGUF из файла работает
- [ ] Ambiguous GGUF (mmproj/embedding): запрос подтверждения появляется
- [ ] Local LLM load в RAM; статус «llama.cpp native»; unload
- [ ] Whisper / SD / Vision / Embeddings грузятся и выгружаются, статусы честные

## 2. CHAT

- [ ] Обычный чат отвечает (local или провайдер)
- [ ] Regenerate
- [ ] Сессии сохраняются после рестарта
- [ ] Чат персоны (Persona chat), RoundTable, Encore

## 3. TOOLS (Phase B — новое)

- [ ] Переводчик короткий (RU→EN): только перевод, без пояснений
- [ ] Переводчик длинный (>2500 символов): чанки, порядок сохранён, Markdown цел
- [ ] Swap языков, Auto-детект, formal/informal, глоссарий
- [ ] Саммари длинного текста: режимы Short/Detailed/Key points/Actions/Timeline
- [ ] Улучшение текста: режимы (грамматика/деловой/короче…), видны Original + Improved + правки
- [ ] Анализатор: карточки Язык/Тон/Настроение/Намерение/Читаемость/Проблемы/Уверенность
- [ ] VibeCode: файлы с именами, копирование файла/всего, пометка «Сгенерировано / на устройстве не выполнялось»
- [ ] Утилиты (8): калькулятор, конвертер, JSON, SHA-256, Base64, URL, статистика, UUID
- [ ] История инструментов: языки/режимы/движок/время; Copy/Share/Save/Chat/Retry
- [ ] Mock-плашка «Mock / template fallback» видна, когда модели нет в RAM

## 4. AUDIO

- [ ] Whisper-транскрибация wav
- [ ] STT auto/RU/EN
- [ ] Скачивание voice engine, TTS озвучка
- [ ] Hands-free режим

## 5. IMAGE

- [ ] SD engine on-demand (скачивание, НЕ внутри APK)
- [ ] Генерация изображения, отмена
- [ ] Vision: вопрос по фото

## 6. MEMORY

- [ ] Заметки: создать/найти/прочитать
- [ ] Индексация (embeddings в RAM) + RAG-запрос

## 7. PERSONAS

- [ ] Создать/править персону, аватар (эмодзи/файл/генерация)
- [ ] RoundTable, Encore

## 8. AGENT (Phase B — новое, маленький реальный)

- [ ] Задача «найди в заметках X и сделай саммари»: план из ACTION-строк виден
- [ ] Шаги со статусами ✅/❌, результат каждого — реальный (не галлюцинация)
- [ ] Недоступное действие (нет whisper/vision) → честное UNAVAILABLE
- [ ] Cancel останавливает, итог честный
- [ ] Прямой ответ помечен, когда действий не требовалось

## 9. SOCIAL (Phase B — чистка)

- [ ] Новый пост стартует с 0 лайков
- [ ] Комментарий, ответ (reply)
- [ ] Репост: видна ссылка «↩ автор: оригинал», бейдж «Репост» (не копия текста)
- [ ] ИИ-черновик; шаблонные fallback-посты с бейджем «Шаблон» (не «ИИ»)
- [ ] Режимы автопостинга описаны честно (REMOTE/TEMPLATE); пауза работает
- [ ] Дубликаты не публикуются; дневной лимит/cooldown

## 10. DATA

- [ ] Backup (с паролем и без) → файл создан
- [ ] Рестарт → Restore из файла → данные + истории инструментов на месте
- [ ] Reset (factory reset) с подтверждением

## 11. UPDATE

- [ ] Проверка обновлений (GitHub)
- [ ] Путь верификации APK (подпись/хэш) доступен

## 12. FAILURE PATHS

- [ ] Отмена скачивания модели
- [ ] Retry после ошибки сети
- [ ] Удаление engine/модели (загруженной — с выгрузкой)
- [ ] Запрос без модели → честный Mock, не fake success
- [ ] Недоступный провайдер → fallback-статус

---

## KNOWN LIMITATIONS (честно, чинится только если всплывёт на S24)

1. Local LLM в фоне для автопостинга не используется (ненадёжно) — фоном только REMOTE-провайдер или TEMPLATE-шаблоны с пометкой.
2. VibeCode-код НЕ выполняется на устройстве — пометка обязательна.
3. Анализатор НЕ определяет «вероятность ИИ-авторства» — такого замера нет.
4. QR-утилита пропущена (нет лёгкой зависимости) — см. `docs/FUTURE_IDEAS.md`.
5. Release-подпись: см. финальный отчёт (debug-кандидат, если секреты не настроены).
6. `release.keystore` + `keystore.properties` закоммичены в репозиторий (до этой сессии) — противоречит `docs/BUILD.md`, решать Lead'у отдельно.
